Contact Manager

Gestor de contactos para la terminal, en Python puro. Lo que ves abajo es el programa real del repositorio, ejecutándose en tu navegador con Pyodide. No se envía nada a ningún servidor: tus contactos viven en la memoria de esta pestaña y se borran al recargar.

python -m app.main
Cargando Python (unos 10 MB la primera vez)…

Pruébalo

Escribe 1 y Enter para añadir un contacto. Prueba un correo inválido y un teléfono repetido para ver las validaciones.

Búsqueda y edición

La opción 3 busca por parte del nombre, teléfono o correo. Al editar, escribe - para borrar un campo.

Exportar

La opción 6 genera el CSV y se activa el botón Descargar CSV de arriba.

Hecho con Pyodide y xterm.js. En el móvil, toca la terminal para abrir el teclado.
